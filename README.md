## 👨‍💻 Sobre Mí

Soy un desarrollador enfocado en la **calidad del software** y la **arquitectura técnica**. Mi día a día se divide entre construir robustos sistemas distribuidores en el backend y crear experiencias de usuario fluidas en plataformas web y móviles.

- 🔭 **Actualmente:** Especializándome en desarrollo nativo Android (**Kotlin + Compose**) y estrategias de evolución de sistemas legacy.
- ⚡ **Mi fuerte:** Arquitectura Hexagonal, Event-Driven Design y Microservicios.
- 💬 **Hablemos de:** Clean Code, TDD, y cómo mejorar la mantenibilidad de un proyecto.
