### 📌 Aplicación Event-Driven de Gestión de Productos
**🔗 [Ver Repositorio](https://github.com/M1guelGtz/proyecto2)**

Sistema de gestión de productos implementando arquitectura hexagonal y patrones event-driven para alta escalabilidad y mantenibilidad.

**Características principales:**
- Arquitectura hexagonal con dominio bien definido
- Eventos de dominio para comunicación entre agregados
- CQRS para separación de responsabilidades
- Saga pattern para transacciones distribuidas
- Testing con cobertura >85%

**🛠️ Stack:** Node.js, TypeScript, MongoDB, RabbitMQ, Docker Compose  
**📚 Aprendizajes:** Patrones avanzados de arquitectura, event sourcing, testing en aplicaciones complejas
